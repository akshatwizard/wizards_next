# Testimonial Collection Template

The old site had no real testimonial quotes anywhere to carry over — checked the homepage, all 11 portfolio pages, About, Career, Blogs, and Contact. The testimonials that were on the new site's draft (Ananya S., Kunal P., and the rest, with specific revenue/lead numbers) were invented placeholder content, not real quotes, so they've been removed rather than replaced with more invented ones.

When you're ready to collect real ones — even 3-4 is enough to bring this section back — send them in this format:

```
Client name (or "Anonymous — [Industry]" if they'd rather not be named):
Their role/title:
The quote: (their actual words — a text message, email, or WhatsApp screenshot works, I'll clean up the wording lightly for the page but won't change the substance)
Star rating, if they gave one:
Photo, if they're comfortable with one being used:
```

Once you have a few, send them over the same way as client briefs — I'll add them to `src/constant/testimonials.ts` and the section reappears on the homepage automatically, no other file needs to change.
